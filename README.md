# Student Management System (Java)

A console-based Student Management System built using Java. This project demonstrates basic Object-Oriented Programming concepts and user interaction through a menu-driven program.

## 🔧 Features
- Add Student
- View Students
- Search Student by ID
- Simple menu-driven interface

## 🧠 Concepts Used
- Classes and Objects
- ArrayList
- Loops and Conditional Statements
- User Input (Scanner)

## 🚀 How to Run

```bash
javac StudentManagement.java
java StudentManagement
```
